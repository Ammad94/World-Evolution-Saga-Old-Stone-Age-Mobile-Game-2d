# 🎨 Content & Asset Pipeline Guide

Everything visual and audible in this repo is **generated by reproducible Python scripts** — no binary source files, no external dependencies. Re-run the tools any time to regenerate or tweak the entire asset base.

```
Tools/
├── assetlib.py   — PNG (palette-encoded) + WAV writers, pixel-art raster engine, Unity .meta writers
├── gen_art.py    — sprites: characters, 15 animals, terrain, vegetation, icons, UI skin, VFX
└── gen_audio.py  — 200+ SFX, 11 biome ambience loops, 7 adaptive music tracks
```

Run from the repo root (plain Python 3, stdlib only):

```bash
python3 Tools/gen_art.py all      # ~9 min → Assets/Sprites (970 PNGs, ~15 MB)
python3 Tools/gen_audio.py all    # ~25 s  → Assets/Resources/Audio (202 WAVs, ~26 MB)
```

Then open Unity → **PrehistoricSurvival → Setup Entire Project** to (re)build prefabs, SOs, scenes and the GameLibrary. Setup is idempotent — sprites keep their GUIDs, and the generated `.meta` files keep import settings stable (PPU, 9-slice borders, multi-sprite sheets, loop flags).

## Art conventions

| Asset | Size | PPU | Layout |
|---|---|---|---|
| Player / NPC frames | 1024×1024 | 512 | one pose per file: `Player/<Action>/<Dir>/player_<dir>_<action>_<i>` |
| Animal frames | 1024×1024 | 256 | `Animals/<Species>/<dir>/<key>_<dir>_walk_<0..3>` + `east/*_attack_0..2`, `east/*_death_0..2` |
| Terrain | 1024×1024 | 1024 | 3 variants per material; water = 4-frame loops |
| VFX | 1024×256 | 256 | single-row sheets (`VFX/spark`, `slash`, `dust`, `blood`, `splash`, `ring`, `fire`, `ember`, `leaf`, `puff`, `snow`, `hitflash`) — sliced at runtime by `SpriteSheetFX` |
| UI skin | 384×384 | 256 | 9-slice borders in meta (`panel_dark`, `panel_parchment`, `button(_pressed)`, `slot`, `bar_frame/fill`, `knob`, `tooltip`, `banner`, `panel_dialogue`, `divider`, `checkbox_on/off`) |
| Item icons | 1024×1024 | 1024 | one icon per item id, loaded by ProjectSetup into `ItemData.icon` |

**Player actions** (8 directions each): `walk` (6f), `idle` (2f), `attack` (3f), `gather` (3f), `swim` (4f), `climb` (2f), `hit` (1f), `die` (3f, south).
`PlayerActionAnimator` plays one-shots and locks the walk animator; triggers come from `WeaponSystem` (attack), harvest systems (`TriggerGather`), damage (`TriggerHit`) and death (`TriggerDie`).

**Animals**: walk frames per 8 directions; attack/death one-shots face-agnostic (side view, auto-mirrored). `AnimalWalkAnimator.PlayAttack/PlayDeath` are invoked by `AnimalAI` (attack) and the `OnDeath` event. New species: add a `SpeciesDef` to `AnimalCatalog`, re-run `gen_art.py animals` + `Setup Entire Project` — prefabs, stats, loot, spawner tables and library wiring all follow the catalog.

## Audio conventions

```
Assets/Resources/Audio/
├── music/     menu_theme, explore_serene, explore_tension, combat_battle, hunt_stalk, season_winter, tribe_dawn
├── ambience/  amb_<biome> (11 loops, day/night variants where relevant)
└── sfx/       step_<material>_<0..2>, swing(_heavy)_, hit_flesh_, chop_, mine_hit_, ui_*, pickup_*, creature voices, weather/fire loops...
```

* Clips are loaded at runtime by path: `AudioManager.Clip("sfx/chop_0")` — no inspector wiring needed.
* **Buses**: Music / SFX / Ambience / UI, each a child `AudioSource` on the `AudioManager`; volumes persist to PlayerPrefs and are exposed in Settings. Master loudness per clip is set in the generator (`save(name, buf, loop, peak)`).
* **Adaptive music**: `DynamicMusicDirector` evaluates threats every ~1.2 s → crossfades `combat` (aggressor chasing within 20 u) → `tension` (aggressive species within 30 u) → `tribe` (near camp) → `winter`/`explore`. Menus force the `menu` layer.
* **Ambience**: `BiomeAmbience` crossfades per-biome loops (night variant for forests); `WeatherAudio` layers rain/storm/wind/blizzard + thunder one-shots.
* **Voices**: creature calls are 3D positional (`PlayVoiceAt`), name-mapped in `AudioManager.VoiceNameFor` (works for all 15 species).
* **Footsteps**: material auto-detected from the biome/river under the player (grass/dirt/sand/snow/stone/mud/wood/shallow), 3 variants each.

Adding sounds: extend `gen_audio.py` (or drop hand-made WAVs into the same folders with `.meta` from any existing file), re-run, then reference by path.

## Content systems

| System | File | Notes |
|---|---|---|
| Era progression | `Content/EraProgression.cs` | Knowledge from crafting/hunting/gathering → Paleolithic → Advanced Stone → Copper Age; banner + fanfare; `Recipe.requiredEra` gates crafting |
| Quests | `Content/QuestSystem.cs` | 10-quest saga chain; objectives subscribe to GameEvents (`collect_*`, `craft_*`, `kill_*`, `place_*`, `era_*`, `visit_camp`, `trade`); rewards = items + knowledge; tracker HUD + toasts; saved |
| Tribe camps | `Content/TribeCampSystem.cs` | 3 camps on walkable land near spawn (tent + campfire + villagers + elder); villagers wander; elder opens trade |
| Trading | `Content/TradeUI.cs` | 8 barter offers, prices improve with friendship (persists) |
| Animals | `Content/AnimalCatalog.cs` | 15 species: stats, biomes, spawn weights, herd sizes, loot, knowledge rewards — drives prefabs (editor), spawning (runtime), loot scaling |
| VFX | `Art/SpriteSheetFX.cs` | pooled one-shot sheets; helpers `FX.Hit/Chop/Mine/Dust/Splash` |
| Game feel | `Feedback/GameFeel.cs`, `UITween.cs`, `DamageNumber.cs` | hit-stop, trauma shake, flashes, pulses, UI pop/fade/slide, damage numbers — all respect **reduced motion** |

### Save data (v1.0.0+)
`SaveSystem` additionally stores `eraIndex`, `eraKnowledge`, `tribeFriendship` and per-quest progress (`quests[]`). Old saves load cleanly — missing fields default.

## Tuning cheatsheet

* Quest difficulty/knowledge → `QuestSystem.BuildCatalog()`
* Era thresholds → `EraProgression.era1Requirement / era2Requirement`
* Music layer ranges → `DynamicMusicDirector` inspector fields
* Camp distance/count → `TribeCampSystem` inspector
* Spawn density/animal caps → `AnimalSpawner` inspector
* Juice intensity → `GameFeel` inspector (hit-stop duration, shake decay, max offset)
* Art regeneration seeds → `RNG = random.Random(seed)` in each generator
