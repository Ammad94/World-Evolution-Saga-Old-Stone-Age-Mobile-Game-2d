# 🦣 Prehistoric Survival - Unity 6 Game Project

## Hyper-Realistic 2.5D Open-World Prehistoric Survival Simulator

A complete Unity 6 game project featuring a **whole-earth**, procedurally generated
open-world survival experience set in the Old Stone Age. Built with URP 2D rendering,
dynamic chunk streaming, a 4-season weather system, and mobile-first touch controls.

### ▶ Run it in three steps
1. Open the project in **Unity 6** (Unity Hub → Add → this folder).
2. Menu **PrehistoricSurvival → Setup Entire Project** (creates prefabs, the
   GameLibrary, both scenes and the build settings). Restart Unity once if it asks.
3. Open `Assets/Scenes/MainMenu.unity` and press **Play** → **NEW GAME**.

Everything is wired automatically: menu buttons, the touch joystick, the HUD, the
pause menu, the world map and the streaming planet.

## 🎮 Features

### Core Systems
- **Whole-Earth World Map** - A full 16,384 × 8,192 tile planet (~40,000 km around)
  with recognisable continents, oceans, islands, mountain belts, rivers and ice caps.
  It wraps around at the date line and is generated from a seed, so nothing is baked
  into a scene file — you can walk anywhere.
- **15 Biomes** - Ocean, Shallow Water, Beach, Glacier, Tundra, Taiga, Temperate Forest,
  Grassland, Steppe, Desert, Savannah, Rainforest, Swamp, Mountain, Snow Peak,
  placed by realistic latitude/altitude/moisture climate rules.
- **Endless Chunk Streaming** - 32×32 tile chunks built over multiple frames around the
  player (7×7 chunks by default) and recycled behind you.
- **Runtime Bootstrapper** - `GameBootstrap` assembles the player, camera, managers,
  joystick and HUD at play time, so scenes stay tiny and always work.
- **8-Directional Sprite System** - Dynamic sprite swapping based on 360° movement
- **Pseudo-3D Depth** - Automatic Y-sorting for realistic depth rendering
- **Mobile Controls** - Dynamic virtual joystick that appears under your thumb

### Survival Mechanics
- **5 Survival Stats** - Health, Hunger, Thirst, Energy, Stamina
- **4-Season Cycle** - Spring, Summer, Autumn, Winter with unique effects
- **Dynamic Weather** - Rain, Storm, Snow, Fog with particle systems
- **Day/Night Cycle** - URP 2D lighting with realistic shadow rotation
- **Consumable System** - Eat food to restore stats

### World Interaction
- **Destructible Tilemap** - Mine stone, dig soil, chop trees
- **Vegetation System** - Timber trees, fruit trees, berry bushes with regrowth
- **Root Digging** - Harvest wild roots from soil
- **Waypoint Navigation** - Open the world map, tap anywhere on the planet to drop a
  pin, and the compass points at it with a live distance readout
- **Living Wildlife** - Biome-aware animal spawner keeps herds and predators around you
  (mammoth herds on the steppe, sabertooths in the jungle, cave bears in the taiga)

### AI & Combat
- **Finite State Machine AI** - Animals patrol, chase, attack, or flee
- **4 Prehistoric Animals** - Woolly Mammoth, Sabertooth Tiger, Cave Bear, Bison
- **Loot System** - Animals drop meat and hides
- **Melee Combat** - Attack with weapons in range

### Crafting & Building
- **Recipe System** - ScriptableObject-based recipe database
- **Crafting Stations** - Some recipes require campfire or workbench
- **Stone Age Items** - Tools, weapons, clothing, buildings

### Traversal
- **Swimming** - Enter water, reduced speed, stamina drain
- **Log Rafts** - Craftable watercraft for ocean/river navigation
- **Climbing** - Scale cliffs and trees using trigger colliders

### Lighting & Atmosphere
- **URP 2D Shadows** - Real-time shadow casting from environmental objects
- **Handheld Lights** - Torches, campfires, stone fat lamps with flicker
- **Seasonal Particles** - Falling leaves, snowfall, rain

## 🛠️ Technical Details

### Architecture
- **Singleton Pattern** - GameManager, ChunkManager, SeasonManager
- **Event-Driven** - EventManager for decoupled communication
- **Component-Based** - Modular systems that can be enabled/disabled
- **ScriptableObjects** - Data-driven items and recipes

### Performance Optimizations
- **Chunk Streaming** - Only load visible world areas
- **Object Pooling** - Reuse footprints, particles, and projectiles
- **LOD System** - Reduce detail for distant objects (implement as needed)
- **Occlusion Culling** - Unity's built-in system for 2D (configure in scene)

### Mobile Optimization
- **Touch Controls** - Optimized for dual-touch input
- **Adaptive Quality** - Quality settings scale based on device
- **Battery Saver** - Reduce frame rate when stats are stable

## Realistic Art & Audio Pipeline (2026-08)

All sprites are now **photorealistic pre-rendered 3D style** (the most realistic
look possible for a 2D top-down game) and all audio is 44.1 kHz layered sound
design. Regeneration pipeline:

| Tool | Purpose |
|---|---|
| `Tools/realart.py` | Slices master sheets (`Tools/sheets/*.png`) into game sprites, keys backgrounds, stabilises frames, writes/patches `.meta` (GUIDs preserved), mirrors UI/VFX/tiles into `Resources` |
| `Tools/qa_sheet.py` | Statistical QA for generated sheets (grid layout, cell coverage) |
| `Tools/gen_audio.py` | Regenerates every SFX/music/ambience file (same names) |

Master sheets are AI-generated with a locked style prompt (magenta chroma
background, consistent camera/light/material language). **All 34 sheets are
present and processed**: player (walk/attack/gather/swim/climb/hit/die), all
15 animal species, villager + elder NPCs, ground, water, trees,
bushes/rocks/grass, 36 item icons, structures, UI (banner/panels/controls/
icons) and 12 VFX strips. Re-run everything with `python3 Tools/realart.py all`.

After pulling: let Unity import, then run `PrehistoricSurvival → Setup Entire
Project` (or Rebuild Game Library + Create Prefabs Only) so prefabs and the
GameLibrary pick up the new art. Previews: Docs/art_preview*.png

World life: animated water tiles (`AnimatedTile`), per-tile ground variants,
wind sway (`WindSystem`) for trees/bushes/grass tufts.
